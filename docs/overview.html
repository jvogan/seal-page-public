Read the transcript

SEAL is a workbench for editing and analyzing DNA, RNA, and protein on your Mac. Start with the built-in Sample Lab. These synthetic examples are included in the app, so you can follow along with the same sequences.

In the sidebar, open Synthetic Reporter. A project groups related Entries, and each Entry holds sequence blocks and notes. Click Synthetic Reporter DNA. The Inspector now shows its name, length, and base composition.

For a sequence of your own, choose New entry and give it a name. Paste a FASTA record into the sequence input. Here, the preview shows FASTA and eighty base pairs. Submit it and check the new block’s name, DNA label, and length.

Drag across some bases to select a range for analysis or annotation. To change one base, click to place the cursor and check substitution mode. Type a replacement, then press Command Z to undo. The original base is restored.

Return to the reporter DNA and open Translate in the Inspector. Choose Whole sequence to compare all six reading frames. Each frame shows its peptide sequence and any internal stops.

Click Detail, then Translate to protein. Amino-acid letters appear alongside the DNA, aligned with their codons. Open ORFs to inspect candidate coding regions.

Now select Synthetic Reporter Protein and open Codons. Back-translation preview shows a proposed coding sequence marked Draft. Review the target host and codon strategy; different codon choices can encode the same protein.

Open Sequence library to reuse a part. Choose Vectors, then SEAL Synthetic Cloning Backbone, and click Add to workspace.

Next, open Cloning and Assembly and select SEAL Demo Plasmid. Click Map to inspect its circular sequence and annotated features. Selecting a feature highlights the corresponding region.

Under Actions, open Restriction digest. Choose Cutters, select AluI, and review the predicted fragments. Their lengths add up to the original plasmid. Click Digest to add each fragment as a sequence block.

On the reporter DNA, open Actions and choose Design primers. Set the target to bases fifty-one through five hundred fifty. Compare the sequences, melting temperatures, and predicted product length. Add selected pair saves primer features on the DNA.

Then open Cloning and Assembly and select SEAL Golden Gate Sample Assembly to inspect its product and linked input parts.

Open Alignments and choose the synthetic Sanger example with paired reads. Fill the window gives the alignment more space. Click Next mismatch to move to a difference between the sequences.

Restore the alignment’s size, then open a read’s chromatogram. Compare the called bases with the signal peaks and quality information to examine an uncertain position.

In Notebook, create a review note. Write what you checked and what you’d like to examine next. SEAL saves the text as you work.

Return to the reporter DNA. Press Command K and choose Build report. In Report handoff, check the source block and choose your attachments: FASTA, GenBank, or a styled report, for example. Expand Package zip preview to inspect the file list.

Click Download ZIP. Then open Activity in the Inspector and find Report package exported. Check its completed status and expand the event for details.

To get SEAL, give your preferred coding agent a SEAL repository you have access to and ask it to set up the app on your Mac. The installation guide covers source builds and an unnotarized GitHub DMG when available. A Mac App Store edition is planned.

You can also connect an agent to your workspace through the command-line tools or MCP. Press Command K and choose Open agent setup for connection instructions. Choose a written guide or an individual video lesson to try a workflow yourself.

Follow along

Install SEAL and open the desktop app. The first workspace guide explains how to load the built-in Sample Lab.

  1. Open SEAL Sample Lab → Synthetic Reporter and select Synthetic Reporter DNA. Check the block’s name, length, and composition in the Inspector.
  2. Create an Entry and paste a FASTA record. Check its preview before adding the block. To practice editing, replace a base and press ⌘Z to undo.
  3. Return to the reporter DNA and compare its reading frames. Inspect ORFs, then select the reporter protein to review its back-translation draft.
  4. Open Sequence library to add a reusable part. In a sample plasmid, inspect the map and run a restriction digest.
  5. Compare primer candidates for the reporter DNA. Open Cloning and Assembly to inspect the sample Golden Gate product and its input parts.
  6. Open a saved Sanger alignment. Use Next mismatch to move through differences, then inspect a read’s chromatogram.
  7. Record your observations in Notebook. Use Build report to choose attachments, preview the ZIP, and export a report. Confirm the export in Activity.
  8. Open agent setup to connect a coding agent through the CLI or MCP.
