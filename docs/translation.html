Screenshots and recordings show the direct edition. Compare editions.

SEAL exposes translation at four levels: a live selection readout, an inline Translate action, a six-frame Inspector, and a reverse-translation draft for protein blocks. CLI and MCP tools cover the same core transformations for automation.

Live selection translation

Select any range in a DNA or RNA block. The Inspector Overview immediately reports the active frame, strand, genetic code, selected nucleotide count, translated amino-acid count, trailing bases that do not complete a codon, and internal-stop warnings. The result follows forward, backward, and circular-origin selections and is announced through an accessible live region.

Inline Translate action

The block toolbar has a Translate to protein button with a dropdown for frame and reverse-strand choices. In compact mode it creates a derived protein block. In Detail mode it can add a saved translation layer to the parent block. The derived result keeps its parent relationship in provenance.

Compare all six frames

Open the Inspector Translate tab for DNA or RNA. Choose the whole block or the current selection, then compare +1, +2, +3, -1, -2, and -3. Frame labels and coordinates are anchored to the parent sequence, including selections that cross the origin of a circular block.

Each row reports its parent range and internal stops. Use Copy for the complete translation or New block to promote it to a derived protein block. Show also reveals the range when the frame maps to one contiguous parent span; it is intentionally omitted for multi-segment origin-crossing selections. Long previews are bounded for rendering, but Copy materializes the complete row.

Back-translate a protein

On a protein block, open Codons to see the Back-translation preview. Choose the whole protein or a selected residue range, DNA or RNA output, and a target host codon-usage table. Built-in choices include E. coli K-12, human, budding yeast, K. phaffii, Bacillus subtilis, and explicitly labelled aggregate proxies for Sf9 and CHO, plus imported custom tables.

Choose a Codon strategy: Max-frequency selects the most frequent synonymous codon by default; Balanced codon usage follows the host frequency distribution; Synthesis-guarded also screens sequence patterns. The preview updates in this panel.

Under Avoid sites, enter enzyme names or motifs, or select saved enzyme sets. All strategies apply this list. Review any unrecognized inputs and sites that remain in the draft.

The preview reports nucleotide length, GC percentage, encoded symbols, and symbols represented by NNN. Stop symbols receive stop codons, including internal stops; later residues remain in the draft. Review the highlighted stop codons and notices, then choose Copy or Draft candidate.

Draft candidate. Many nucleotide sequences can encode the same protein. The selected strategy and site preferences determine this candidate; review it for your experiment before using it.

CLI translation and frames

The separately built Rust CLI accepts an inline sequence, file path, or stdin. translate uses frame offsets 0, 1, or 2. frames returns all six frames. Add --json for structured output.

seal translate ATGAAATAG
echo ATGAAATAG | seal translate --frame 1 --json
seal frames ATGAAATAG --json

MCP translation

The local MCP transform tool supports translate, translate_all_frames, translate_from_atg, and reverse_translate. It also supports codon optimization as a separate transformation. The source MCP currently exposes a smaller set of NCBI table IDs than the desktop app, so clients should validate the tool schema rather than assume every desktop option is available.

{
  "sequence": "MSTNPKPQR",
  "type": "reverse_translate",
  "saveTo": "Synthetic reverse-translation draft"
}

Find ORFs

Run seal orfs to detect open reading frames in all six frames. Set the shortest result to keep with --min-aa, which defaults to 30. Use seal analyze with --min-orf-aa to include ORFs in a larger sequence summary.

seal orfs --file synthetic-region.fa --min-aa 50 --json
seal analyze --file synthetic-region.fa --min-orf-aa 50 --json

In the app, the ORFs tab applies the active genetic code and marks an ORF Annotated when it overlaps an annotated CDS on the same strand by at least 50 percent, or Partial otherwise.

Genetic codes

The desktop app includes 22 NCBI translation tables and supports per-block overrides and locally stored custom codes. A custom code starts from a built-in table and can reassign codons or add start codons. The active choice applies consistently to translation, ORF detection, and protein analysis for that block.
