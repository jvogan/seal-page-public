What the notebook is

The notebook is a full-pane document space for protocols, results, and design rationale. It is organized as a three-level tree:

  • Projects group your notebooks, matching the project scope you already use elsewhere in SEAL.
  • Notebooks hold pages. Each notebook belongs to one project, or to the "No project" bucket.
  • Pages are individual rich-text documents.

Pages are standalone documents, not text blocks riding inside a conversation. They are stored in the same on-device workspace as the rest of SEAL, so a notebook is backed up and exported together with your conversations, blocks, and features. See Architecture for how that workspace is laid out.

Writing notes

Open a page to write in a rich editor. The formatting toolbar covers the common marks and blocks:

  • Inline formatting: bold, italic, strikethrough, inline code, highlight, link, subscript, and superscript.
  • Headings: heading 1, heading 2, and heading 3.
  • Blocks: bullet list, numbered list, checklist, quote, and code block.

The toolbar collapses to a compact subset when you want more room, and the same actions stay reachable from a floating menu when you select text. Use the Insert menu to add a table, import a spreadsheet, add an image, insert a reference, or drop a divider.

Tables, spreadsheets, and images

Insert a table from the Insert menu, or paste spreadsheet data (from Excel, Google Sheets, Numbers, or a tab-delimited source) directly into a page to get a clean table. Import a CSV, TSV, or XLSX file the same way. Paste or drop an image to embed it; pasted and dropped images are downscaled before they are stored inline.

Comments

Select a span of text and add a comment to start an inline thread anchored to that text. Threads can be edited, resolved, reopened, and deleted. Resolved threads stay attached but render muted and drop out of the open count.

Page titles

A page title is optional. When you leave it blank, the title is derived from the first line of the page so the tree does not fill with "Untitled page" entries. Double-click a page in the tree to rename it.

Reference a sequence

A page can reference an entry (a conversation), a specific block within an entry, a base range within a block, or another notebook page. References are stored as a link, so they also appear in the page's linked-entries panel and as backlinks on the entry side.

To insert a reference inline, type @ at a word boundary to open the reference picker, then search for the target. Move through the results with the arrow keys and press Enter to commit the highlighted option. You can also insert a reference from the Insert menu or the slash menu.

A reference renders as an inline chip. Click it to navigate to its target. The chip's label is derived from the live entry, block, or page, so renaming the target updates the chip immediately. If the target is deleted, the chip falls back to the label captured when you created it.

To reference a base range, select the range in a block first, then open the reference picker. The selected range appears as an option you can pick directly.

Slash commands

Type / in a page to open the slash menu and insert a block at the caret. The menu offers the same blocks as the toolbar plus a few insert actions:

  • Headings 1 through 3, bullet list, numbered list, checklist, quote, highlight, code block, and divider.
  • Table, Spreadsheet (import a CSV or Excel file), Image (upload or paste), and Reference (link an entry).

Filter the list by typing after the /. When nothing matches your query, the menu shows a hint row instead of disappearing, and arrow keys, Enter, and Escape still behave as usual.

Organize

The tree on the side of the notebook lists every project, notebook, and page. A search box filters by page title and body text, including tags, and highlights the matching text.

  • Collapse a notebook with the chevron in its header. Collapse state is saved, so the tree looks the same after you reload.
  • Move a notebook to another project from the move control in the notebook's header row. The menu lists every project plus "No project" and marks the current one. A notebook moved to a project is appended to the end of that project's order.
  • Reorder notebooks by dragging a notebook header onto another notebook in the same project. Moving a notebook across projects still uses the move control above.
  • Reorder or move pages by dragging a page onto another page to place it before that page, or onto a notebook header to move it into that notebook.

You can dock the notebook list on the left, on top as a tab strip, or on the right, and resize the side rail by dragging its divider. Export a single page or a whole notebook as Markdown or HTML, or print a page to PDF, from the export menu under the editor.

Persistence and live-sync

Notebook edits are saved automatically to the local workspace. Writes are debounced while you type, and a pending write is flushed when the window closes, so an edit made just before quitting is not dropped.

The notebook stays in sync with the rest of the workspace in both directions:

  • Renaming an entry, block, or page updates every reference chip that points to it.
  • Deleting a conversation, block, or page removes the links that targeted it, so the page panel does not keep a stale reference.
  • Importing a workspace re-reads the notebook tree and its collapse state.

Deleting a notebook or page captures a restore point first and shows an Undo control, so an accidental delete is recoverable. If the stored notebook data cannot be read or was written by a newer build, SEAL pauses saving to avoid overwriting it.
