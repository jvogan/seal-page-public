Release status

SEAL is coming to the Mac App Store first. The source repository and direct-download edition will launch later. The details below describe source capabilities, not an approved Store release.

Read the edition comparison for Store features and source-only tools. Public source installation instructions will follow the source release.

Source capabilities

  • Live selection translation. Selecting DNA or RNA updates frame, strand, genetic code, amino-acid count, trailing-base, and internal-stop reporting in the Inspector.
  • Six-frame Translate Inspector. Compare forward and reverse parent-anchored frames over a selection or whole nucleotide block, then copy, reveal, or create a derived protein block.
  • Reverse-translation drafts. Protein blocks can produce DNA or RNA candidates with a chosen host table, GC and residue reporting, explicit unknown and stop warnings, and an unoptimized, not-ready-to-order boundary.
  • SEAL Sample Lab. Project-authored deterministic synthetic fixtures support the documented sequence, cloning, notebook, and Activity workflows.
  • Linked sample maps. Representative circular DNA, linear DNA, and protein samples open with a linked map above or below the sequence, while other records retain the standard sequence view. Map-only and floating layouts remain available from the same menu.
  • Alignment and trace review. Identity reporting reserves 100% for exact agreement, separates high-quality from unqualified mismatches, and keeps the last valid alignment visible when a rerun fails.
  • Golden Gate and GoldenBraid sample workflow. Synthetic parts, backbones, a sample product, an Activity record, and notebook context are linked in the demo workspace.
  • Consistent GoldenBraid naming. The name remains stable through Activity, Inspector, provenance, reports, exports, and MCP workspace readback.
  • Packaged terminal dock. Packaged builds enable the environment-sanitized terminal bridge, which SEAL_ENABLE_TERMINAL can turn off.
  • Terminal resilience. Long line-mode commands remain readable, and a command draft stays available if a terminal write fails.
  • Native analysis expansion. The native Rust surface covers restriction mapping, ORFs, GC, repeat finding, and alignment or diff.

Alignment examples and workspace controls

  • Saved alignment examples. The Alignments page includes six synthetic examples with saved MUSCLE or Clustal Omega results, including primer-linked Sanger reads and a 12-sample DNA panel.
  • Example downloads. Download FASTA inputs and, for trace examples, AB1 files and primer sequences.
  • Sequence library. Import files or fetch database records from the library toolbar. Select multiple parts to export or delete them together.
  • Entry selection. Move, export, or archive selected entries together. Archived entries can be restored or deleted in groups.

Interface and automation

  • Entries are the user-facing workspace records. CLI and MCP keep the underlying conversation API term for compatibility.
  • The source MCP server exposes 61 tools and 5 resource types. It requires a source checkout, npm ci, absolute checkout-local tsx, and an explicit SEAL_DB_PATH when sharing the installed app database.
  • Agents use block_list and block_get to read shared sequence blocks. workspace_list reads MCP Scratch. MCP scratch deletion tools are disabled.
  • The separately built Rust seal CLI exposes 35 canonical commands.
  • Notion Team Sync remains alpha schema and policy tooling. Provisioning, publishing, queue processing, OAuth installation, and bidirectional sync remain planned.
