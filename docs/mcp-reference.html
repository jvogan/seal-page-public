MCP tool reference

This guide covers source and direct-edition tools. These tools are not bundled with the first Store release. Compare editions.

All 61 SEAL MCP tools, grouped by module. Each entry lists the tool's purpose, its arguments, and a minimal example invocation as a JSON object matching the input schema.

After npm ci in a source checkout, run the server with the checkout's absolute node_modules/.bin/tsx and mcp/server.ts paths over stdio. The installed app does not bundle this runtime. For setup and per-client configuration, see MCP setup. Arguments below are the fields passed in each tool call; required arguments are marked in the Required column.

Use block_list and block_get to read sequences across the shared SQLite workspace. Workspace and bio tools resolve sequences from the MCP Scratch list. Project and conversation tools operate across the shared database. Scratch name lookup tries an exact ID, a case-insensitive exact name, then a partial name match.

Workspace

Seven tools manage the flat in-process sequence list, the MCP scratch workspace. All bio operations resolve sequences by name from this list. Source: mcp/tools/workspace-tools.ts.

workspace_add

Add a sequence to the workspace. Accepts raw sequence, FASTA, or GenBank format. Auto-detects type and optionally auto-annotates.

ArgumentTypeRequiredDescription
sequencestringyesSequence content (raw, FASTA, or GenBank).
namestringnoName for the entry; auto-generated if omitted.
typeenumnodna, rna, protein, misc, unknown, or mixed. Overrides auto-detection.
topologyenumnolinear (default) or circular.
notesstringnoOptional notes.
tagsstring[]noOptional tags for filtering.
autoAnalyzebooleannoRun auto-annotation (default: true).
 
{
  "sequence": "ATGAAAGCGATCGAT...TAA",
  "name": "MyGene",
  "topology": "linear",
  "tags": ["insert", "cds"]
}

Reassign the display position of blocks in a conversation. The order array must contain exactly the same set of block ids currently in the conversation. Runs in a single transaction; if validation fails the database is unchanged.

ArgumentTypeRequiredDescription
conversationIdstringnoConversation to reorder (defaults to the MCP scratch conversation).
orderstring[]yesComplete ordered list of block ids (must be the exact same set as current).
 
{
  "order": ["block-uuid-1", "block-uuid-2", "block-uuid-3"]
}

block_extract_selection

Extract a sub-sequence from an existing block into a new child block. On linear blocks, start must be <= end. On circular blocks, start > end is allowed (concatenates raw[start:] + raw[:end]). The extracted block always has topology linear.

ArgumentTypeRequiredDescription
blockstringyesSource block name or id (fuzzy resolved).
startintegeryes0-indexed start position (inclusive).
endintegeryes0-indexed end position (exclusive). For circular wrap-around, pass start > end.
newNamestringnoName for the new block (defaults to "{sourceName}[{start}..{end}]").
 
{
  "block": "seal-synthetic-backbone",
  "start": 120,
  "end": 480,
  "newName": "Synthetic backbone review fragment"
}

block_annotate_selection

Add a feature annotation to a block, pinning it to a specific start and end range. The start and end values override whatever the incoming feature object contains.

ArgumentTypeRequiredDescription
blockstringyesBlock name or id (fuzzy resolved).
startintegeryesFeature start position (0-indexed, inclusive).
endintegeryesFeature end position (exclusive).
featureobjectyesFeature properties (see sub-fields below).
feature.typestringyesFeature type (e.g. gene, CDS, promoter).
feature.namestringyesFeature label.
feature.idstringnoOptional feature id (auto-generated if absent).
feature.strand1 | -1 | 0noStrand.
feature.colorstringnoUI color hint.
feature.notesstringnoFree-text notes.
 
{
  "block": "synthetic-reporter",
  "start": 0,
  "end": 720,
  "feature": {
    "type": "CDS",
    "name": "Synthetic Reporter CDS",
    "strand": 1,
    "color": "#22c55e"
  }
}
