SEAL editions

SEAL is coming to the Mac App Store first. The source repository and direct-download edition will launch later.

First Store release

The Store edition focuses on sequence editing, maps, built-in analysis, cloning plans, Library, Notebook, Activity, and reports. It uses the bundled computation engine and local workspace storage.

Workspace permissions

The Store edition uses a sandbox-managed default workspace. Its native file and folder pickers grant access to files you select. File → Workspace can select a workspace folder containing .seal/seal.db.

The Store and direct editions have separate default data and preferences. Move records between editions with an explicit workspace backup and restore; installing another edition does not automatically move your data.

Source and direct-edition tools

Agent setup, terminal, MCP, and CLI guides describe separately installed source tools and direct-edition workflows. They do not describe software bundled with the Store app.

The Store app does not launch external agents. A separately installed tool may be able to use an explicitly selected shared workspace, but this is not a supported Store workflow until it has been verified in the signed sandboxed app.
