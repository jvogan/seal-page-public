Quickstart

This guide includes source and direct-edition features. Check the edition comparison for the first Store release. Screenshots and recordings show the direct edition. Compare editions.

Load a sequence in SEAL, inspect its features, run an analysis, and export a report.

First, install SEAL and open the app. This walkthrough uses the desktop app. For a guided introduction, start with Your first workspace or the video tutorials.

1. Load a sequence

In the sidebar, expand SEAL Sample Lab and open Synthetic Reporter. If the project is missing, click New entry, press Escape to leave its name field, then click Load demo workspace. To use a pasted or imported sequence instead, follow Add your first sequence.

To retrieve a public record, open Sequence library in the sidebar and click Fetch database in its toolbar. Fetching sends a request to the selected database; the synthetic samples work offline. See Sequence sources.

2. Inspect the sequence

Click inside Synthetic Reporter DNA. Its header shows DNA, 720 bp, and linear. Open Overview in the Inspector to compare its name and length. If the panel is hidden, click Show inspector in the workspace header. Open Features to inspect the annotations.

To find a tool by name, press ⌘K to open the command palette, type its name, and select the matching result.

3. Preview a restriction digest

Open Actions beneath the DNA sequence and choose Restriction digest. In the dialog, select an enzyme and read the cut count and fragment preview. The preview updates as you change enzymes. Click Cancel when you finish inspecting; Digest creates fragment blocks. See the digest guide for a complete example.

4. Inspect translation

Drag across a short DNA range. In the Inspector, open Overview and scroll to the Selection card to read its translation. Open the Inspector’s Translate tab to compare all six frames over the selection or the whole block.

For a protein block, open Codons → Back-translation preview for a DNA or RNA draft. Review the host table and any unknown-residue or internal-stop notices before saving. See Translation and ORFs.

5. Review and export

With a sequence block active, open the Inspector’s Activity tab to review recorded operations. Previewing a digest or translation leaves the sequence unchanged.

Click the block you want to report on, press ⌘K, type Build report, and select that command. In Report handoff, review the source block and choose files under Attachments. Click Download ZIP to save the package, which includes a manifest and validation file. Use GenBank when feature annotations and topology need to survive export.

Optional: try the CLI in a scratch workspace

The CLI requires a source checkout and a separate build. Follow the CLI setup instructions first.

In your checkout, run this example in a subshell. It creates a temporary database for the synthetic fixture and leaves your shell's workspace setting unchanged:

(
  export SEAL_DB_PATH="$(mktemp -d)/quickstart.db"
  DEMO=tests/fixtures/release-bio/seal-synthetic-reporter.gb
  seal import "$DEMO"
  seal info "$DEMO"
  seal analyze "$DEMO" --min-orf-aa 50 --json
  seal sites "$DEMO" --unique
  seal digest "$DEMO" --enzymes EcoRI,BamHI --preview
  seal export markdown --include-analysis --output report.md
)

This exercise writes to a separate database. Its imported blocks and Activity records appear there, not in the desktop workspace. The report is saved as report.md in the working directory.

To work with the desktop workspace, set SEAL_DB_PATH to the active path supplied by SEAL. Press ⌘K, type Open agent setup, and select the command to find it. Verify the connection with a read-only block listing before importing or editing data.
