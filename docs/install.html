Install SEAL

Coming to the Mac App Store. SEAL will launch there first; the source repository and direct-download edition will follow later.

Mac App Store

The Store edition is not available yet. A link to its listing will appear on the SEAL home page when it is ready to download.

Read Edition differences for the first Store release's tools, workspace permissions, and agent-tool boundary.

Source distribution

The source repository has not launched publicly. Source-build instructions will be added when that distribution is available.

Direct downloads

The GitHub app distribution will launch after the Store edition. No public DMG download is offered here yet.

Agent-assisted installation

Agent-assisted source installation belongs to the later source distribution. It is not required to install the Store edition.

External MCP and CLI tools

The source MCP server and Rust CLI are separate from the Store app. The initial Store configuration does not launch agents or include a terminal. Shared-folder interoperability with separately installed tools remains experimental.

Read the source-tool boundary before using developer setup guides.

Workspace storage

The Store edition uses its own sandbox-managed workspace by default. A folder chosen through File → Workspace contains the workspace database at .seal/seal.db. Direct and source editions use separate defaults.

See Privacy for storage, network requests, and support contact information.
