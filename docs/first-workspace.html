Read the transcript

Start with SEAL open. This workspace is empty. Select Load demo workspace to add the sample sequences, notebook pages, and saved alignments. The examples use synthetic data.

In the left sidebar, expand SEAL Sample Lab and open Synthetic Reporter. The center of the window shows an Entry. An Entry groups related sequence blocks and notes.

Select Synthetic Reporter DNA. The Inspector on the right shows information for that block. In Overview, check the sequence length, molecule type, and base composition. The example DNA has seven hundred and twenty bases.

The sidebar also opens other parts of your workspace. Notebook contains lab notes. Alignments contains saved sequence comparisons, including examples with Sanger reads.

Return to Synthetic Reporter to continue working with its sequences. You can move between these pages while keeping the same workspace open.

Before you start

Install SEAL and open the desktop app. You can follow this guide offline with the bundled sample data.

1. Open the Sample Lab

  1. In the sidebar, find SEAL Sample Lab under Projects. Expand the project if its entries are hidden.
  2. Select Synthetic Reporter. The workspace opens the entry’s blocks.
  3. Find Synthetic Reporter DNA. Its header shows DNA, 720 bp, and linear.

If the sample project is missing, click New entry. Press Escape to leave the entry-name field, then click Load demo workspace in the empty workspace. Return to SEAL Sample Lab → Synthetic Reporter.

Expected result: you can read the synthetic DNA sequence and see the entry name in the workspace header.

2. Find the parts of the workspace

PartWhat it holdsIn this example
ProjectA group of related entries.SEAL Sample Lab
EntryRelated sequence and note blocks.Synthetic Reporter
Sequence blockOne DNA, RNA, or protein sequence with its own name, type, and features.Synthetic Reporter DNA
InspectorDetails and tools for the active block or selected sequence range.Overview, Features, Restriction, Translate, and other tabs.
  1. Click inside the Synthetic Reporter DNA block to make it active.
  2. Open Overview in the Inspector. If the Inspector is hidden, use Show inspector in the workspace header.
  3. Compare the Inspector’s block name and length with the block header.
  4. Open Features to inspect the sample’s annotations.

Expected result: the Inspector names the DNA block you selected. Selecting another block changes the Inspector’s contents.

3. Select part of the sequence

  1. Drag across a short run of DNA letters in the sequence block.
  2. Open Translate in the Inspector to inspect reading frames for the selected range.
  3. Read the displayed range before copying a result or creating a derived block. For this walkthrough, leave the sequence unchanged.

Expected result: the sequence letters are highlighted, and the translation preview refers to your selection. See Translation and ORFs for the frame controls.

4. Show a map with the sequence

  1. In the sidebar, open Cloning & Assembly and find SEAL Demo Plasmid.
  2. Open the arrow beside Map in that block’s header. The menu is labelled Map layout.
  3. Choose Map above sequence. Compare the map’s feature labels with the sequence block.
  4. Try Map below sequence, then choose Sequence only to hide the map.

Expected result: map placement changes for the same block; its sequence remains intact. The map guide covers floating and side-panel layouts.

If you lose your place

  • The sidebar looks empty: clear Search projects and entries, then expand SEAL Sample Lab.
  • The Inspector shows another sequence: click the intended block and compare its name with the Inspector heading.
  • The sequence is hidden by a map: open the block’s Map menu and choose Sequence only.
  • You accidentally edit sample bases: use ⌘Z immediately to undo the edit, then check the sequence again.
