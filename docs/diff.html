Sequence diff

Screenshots and recordings show the direct edition. Compare editions.

Compare two sequences base by base. seal diff reports the mismatches, insertions, and deletions between them.

Run a diff

Run seal diff with two sequences. Each can be an inline string, a file path, or a library name.

seal diff ATGCGT ATGCAT

To compare two files, pass both paths.

seal diff seq1.fa seq2.fa

Add --json for structured output, and --save to write the result to a file.

FlagTypeDescription
--jsonflagEmit structured JSON instead of text.
--savestringWrite the output to the given file path.
 
seal diff seq1.fa seq2.fa --json --save diff.json

Reading the output

diff reports three kinds of change between the first sequence and the second:

  • Mismatch: a base differs at the same position.
  • Insertion: a base is present in the second sequence but not the first.
  • Deletion: a base is present in the first sequence but not the second.

Two identical sequences report no changes. Use the diff to confirm a single point mutation, to check an insert against its reference, or to verify that an edit changed only what you expected.

To compare a sequence against its own saved history rather than a second sequence, use seal checkpoints diff, which reports length, topology, type, and feature changes between two checkpoints of one block. See the CLI reference.

Over MCP and the desktop app

Agents connected over MCP compare sequences with the compare tool. It accepts two sequences as workspace entries by name, as inline sequences, or a mix of the two.

{
  "tool": "compare",
  "arguments": {
    "seq1": "synthetic-reporter-reference",
    "seq2": "synthetic-reporter-recoded"
  }
}

To compare an inline sequence against a stored entry, pass an object for either side.

{
  "tool": "compare",
  "arguments": {
    "seq1": { "name": "Synthetic Reporter DNA" },
    "seq2": { "sequence": "ATGGTGAGCAAGGGCGAGGAG..." }
  }
}

See the agent control plane for how agents read and write the same workspace, and the MCP tool reference for the full tool list.
