Before you start

Open the SEAL desktop app. If you are new to its layout, follow Your first workspace first. This exercise writes one practice block to your local workspace.

Use this synthetic 80 bp record to practice the FASTA format.

1. Copy the practice FASTA

Copy the entire record, including the first line that starts with >. That line names the record. The four remaining lines contain 80 DNA bases; line breaks do not count toward the length.

>SEAL_beginner_practice
ACGTTGCAAGTCCTGATCGA
TGACCTAGGATCGTACCAAT
CGATTCAGGCTAACGTTCGA
TACGAGCTTAGCATGACCTG

2. Paste it into a new entry

  1. Click New entry in the sidebar.
  2. When the entry-name field opens, enter FASTA practice and press Enter.
  3. Click Paste a sequence… in the composer and paste the complete record.
  4. Read the input preview. It should identify FASTA and 80 bp.
  5. Click the upward-arrow submit button, or press ⌘Enter. The button’s tooltip names the format and length being added.

A clean record can be added directly. If Review import opens, check the record name, DNA type, and 80 bp length, then click Import 1 record. Use Cancel if these values differ from the example.

Expected result: a sequence block named SEAL_beginner_practice appears in the entry. The composer clears after a successful addition.

3. Verify the imported block

  1. Find SEAL_beginner_practice in the block header. Confirm that its molecule type is DNA and its length is 80 bp.
  2. Click inside the block, then open Overview in the Inspector. Use Show inspector in the workspace header if the panel is hidden.
  3. Check that the Inspector names the same block and reports 80 bp.
  4. Compare the beginning and end of the sequence with the example: it starts with ACGTTGCAAG and ends with GCATGACCTG.

Expected result: one DNA block contains all 80 bases. FASTA supplies a name and sequence; this example carries no feature annotations.

4. Import a file instead

This is an alternative to pasting. To try both routes, use another new entry named FASTA file practice. A second import can report Exact sequence already exists; that is expected when you deliberately add the same practice sequence again.

  1. In a text editor, save the complete example as a plain-text file named seal-beginner-practice.fasta.
  2. Open your empty practice entry in SEAL and click Import file. Select the saved file. You can also drag the file into the workspace.
  3. If Review import opens, confirm FASTA, one record, the record name, DNA type, and 80 bp. Click Import 1 record.
  4. Repeat the block and Inspector checks from step 3.

Expected result: the file produces the same name, sequence type, and 80 bp length as the pasted record.

Fix an input problem

  • The preview says text or Unknown: replace the composer contents with the complete FASTA example. Include the > header and exclude surrounding instructions.
  • The length differs from 80 bp: cancel an open import review and compare all four sequence lines. If a block was already added, use a fresh practice entry for the corrected record so you can compare the two.
  • SEAL asks you to choose DNA or RNA: check for an accidental U. This example contains only A, C, G, and T. Correct the pasted text before submitting.
  • A name already exists in this entry: change the incoming record name in the review or cancel and create a fresh practice entry. An exact-sequence warning can still appear because SEAL also checks other entries. Replacing a record changes an existing block.
  • The import fails: confirm the saved file is plain text. After a failed paste, the composer keeps its contents so you can correct them and try again.
