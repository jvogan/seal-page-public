Workspace

Edit and inspect sequences.

First start.

Paste a sequence or import a file. You can also load synthetic samples, fetch a sequence, or browse the Library.

Sequence workbench.

Sequence blocks stay editable. Feature tracks and per-block stats are visible inline. Drag to reorder, paste from the clipboard, or import FASTA, FASTQ, GenBank, EMBL, GFF, SBOL, binary DNA, ABI, PDB/mmCIF, CSV, or registry JSON.

Linked sequence maps.

Representative circular DNA, linear DNA, and protein samples include linked maps. Use the Map menu to show a map on its own, above or below the sequence, or in a floating panel.

Translate

Translate DNA, RNA, and protein.

Translation on the sequence.

Show translated amino acids above the DNA sequence and compare reading frames in the Inspector. Select a range to inspect its translation without creating a derived block.

Six parent-anchored frames.

Compare +1, +2, +3, -1, -2, and -3 with coordinates and internal-stop marking. Copy the complete row, show it on the parent, or create a derived protein block.

Reverse-translation draft.

Open Codons on a protein block. Choose DNA or RNA, a host table, and a codon strategy, then enter enzyme names or motifs under Avoid sites. Review length, GC, remaining sites, stop codons, and NNN placeholders before copying or creating a draft.

Cloning

Digest and assembly workflows.

Constructs and assembly methods

Start an assembly with DNA parts from your workspace. Choose the destination Entry and open a builder, or return to a saved construct.

Read the guide →

Restriction digest, 154 enzymes.

Searchable enzyme list with Common / All toggle. Cut-site results stay tied to the active block for reviewing predicted fragments. Inline restriction site markers can also be turned on in the canvas.

Primer design.

Design forward and reverse primers from a selection. Each candidate shows Tm, GC%, length, and self-dimer warnings. Send the pair into PCR simulation, or hand off to Gibson and Golden Gate planners with overhang scaffolding pre-filled.

Clone Builder.

Clone Builder coordinates vector and insert workflows. Pick a vector and insert, preview compatibility, then continue with Gibson, Golden Gate, or a basic restriction-ligation flow. SEAL records scar information with the result.

Gibson assembly.

Gibson planner uses overlap melting temperature, overhang length, and end compatibility to assemble fragments. The dialog shows the construct preview and per-junction warnings before you commit.

Golden Gate Type IIS.

Golden Gate orders fragments by overhang. Block-filter and internal-site badges flag incompatible inserts before you commit. The order rows are drag-reorderable.

Ligation with scar tracking.

For workflows that do not need an assembly planner, ligate two compatible DNA fragments directly. Scar information remains available for downstream analysis.

Compare and inspect sequences.

Guide design

Find guide candidates and compare their sequence properties. Review the selected guide in the Inspector before adding it to your work.

Protein properties

Inspect a whole protein or a selected range. Review composition and calculated properties alongside its sequence.

Sequence diff.

Compare two blocks and inspect insertions, deletions, and substitutions. Use the comparison to check a mutation or review a sequence edit.

Command palette routing.

Cmd-K opens a searchable command surface. digest synthetic routes to the restriction workflow with the active synthetic backbone, while primer reporter routes to primer design for Synthetic Reporter DNA.

Multiple sequence alignment.

Align three or more sequences from the workspace. Useful for ortholog comparisons, primer design across variants, or sanity-checking a translation against multiple references.

Library

Search NCBI or UniProt by accession or keyword, then import a sequence into your workspace. The search runs when you request it.

Provenance

Activity records workspace changes.

Agent control plane.

The Start Panel provides the database path, MCP config with the resolved SEAL_DB_PATH, and Agent Doctor. Agent Doctor checks path alignment, watcher health, schema version, Activity hydration, and recent external writes.

Activity trail with source labels.

External mutations use a source label such as UI, MCP, or CLI. If a client supplies an accepted provider tag, Activity also shows the client label. Activity links to the affected block and shows a pre-write checkpoint for recoverable destructive block changes.

Zoomed Activity row.

Expand an event to inspect its details. Available checkpoint controls stay attached to the event.

Checkpoint recovery.

Activity displays a restore action only for changes with a recoverable checkpoint. Creates, position-only changes, and reads have no rollback snapshot.

Handoff

Export a report package.

Report handoff.

Select blocks. Pick formats (Markdown, FASTA, GenBank, CSV, styled HTML) and a style preset (review, compact lab note, publication, teaching, monochrome). Output is a portable zip with manifest.json and validation.md. GenBank preserves metadata. FASTA and CSV are intentionally lossy summaries.

Compact responsive layout.

The same workbench at a 390-pixel width. Stats, features, ORFs, and Activity reflow without losing function. Useful when you split the screen with another tool, or on a smaller MacBook.
